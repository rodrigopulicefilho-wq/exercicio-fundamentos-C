# exercicio-fundamentos-C

Aplicação desenvolvida em Linguagem C que simula um contador dinâmico controlado pelo usuário via terminal.

---

### 💻 Destaques do Código
- **Estruturas de Controle:** Uso de laço infinito (`while(1)`) com ponto de parada (`break`).
- **Tratamento de Entrada:** Limpeza de buffer para evitar falhas caso o usuário insira caracteres não numéricos.
- **Lógica Condicional:** Validação de opções com `if/else`.

---

### 🛠️ Tecnologias Utilizadas
- Linguagem C
- Compilador GCC / Clang
